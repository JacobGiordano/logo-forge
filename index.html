Levels

Remaps the source image's tones before thresholding — any pixel at or darker than this brightness becomes pure black. Raise it to deepen faded blacks or crush out light scan noise; 0 leaves the darkest source tones untouched.

Remaps the source image's tones before thresholding — any pixel at or brighter than this brightness becomes pure white. Lower it to brighten a dingy or yellowed background; 255 leaves the lightest source tones untouched.

Curves the midtones between the black and white points without moving pure black or pure white. Values above 1 brighten midtones, pulling more into the traced logo; values below 1 darken them; 1.0 leaves the curve linear (off).

Binary mask

Chooses how the light/dark split works. Auto (Otsu) picks a brightness cutoff automatically from the image's own tones; Manual lets you set the cutoff yourself with the Threshold slider below.

Only takes effect in Manual mode. Sets the brightness cutoff separating logo from background — pixels darker than this become part of the traced shape. Raise it to pull in lighter grays as logo; lower it to keep only the darkest pixels.

Only takes effect in Auto mode. Nudges the automatically detected cutoff up or down. Positive values pull in lighter grays as part of the logo; negative values keep only the darkest pixels.

Removes small stray specks and isolated blobs from the mask before tracing — handy for cleaning scan noise or JPG artifacts. Higher values remove larger specks; 0 turns it off. Too high and it can eat fine details like thin serifs or small dots.

Fills small enclosed gaps inside the traced shape — like antialiasing pinholes or dust — instead of leaving them as separate cutouts. Higher values fill larger gaps; 0 leaves every interior hole intact. Too high and it can fill in real design holes, like the counter of an "e" or "o".

Controls how sharp or rounded corners are in the traced outline. At 0, corners stay crisp and geometric; higher values round them off, which can smooth out pixel stair-stepping but will also soften intentionally sharp corners.

Vector fit

Controls how tightly curved segments hug the traced pixel outline. Lower values fit curves more tightly and faithfully; higher values let curves flow more loosely and smoothly. Has little visible effect on shapes with very sharp, geometric corners — it only refines curves the tracer already decided to draw, not straight edges.

Reduces the number of points along straight-line sections of the path for a cleaner, smaller SVG — a pure cleanup pass that never touches curved segments. Higher values remove more points; 0 leaves every traced point untouched.

Supersampling

Bilinear-interpolates the source's continuous grayscale at 2× resolution and thresholds it there, instead of thresholding first and smoothing the binary mask afterward — this preserves true sub-pixel edge position for smoother, more accurate curves. Capped at 2× (higher factors aren't supported); very large images that would exceed the size limit automatically fall back to tracing at native resolution instead. Off skips this step.

Chooses which pixels count as the logo versus the background. Auto-detect guesses this from the image's overall brightness; use Normal for a dark logo on a light background, or Inverted for a light logo on a dark background.

The new pipeline cleans the bitmap first, then traces cleaner silhouettes with fewer, smoother paths. 2× supersampling bilinear-interpolates the source at double resolution before thresholding for smoother sub-pixel edges, then traces at that resolution and scales the result back down to the source size; very large images fall back to tracing at native resolution automatically.
